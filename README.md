Автор: Кроссов Илья

Технологии: Python, Telebot, Groq, os, subprocess, time, datetime

🧠 Описание проекта

Jarvis — это интеллектуальный голосовой и текстовый ассистент, вдохновлённый ИИ-помощником Тони Старка из фильма "Железный человек".

Моя версия Jarvis написана на Python и интегрируется с Telegram-ботом, чтобы управлять компьютером и взаимодействовать с пользователем на расстоянии.

⚙️ Возможности

🖥 Управление компьютером

Открытие и закрытие программ

Поиск и запуск файлов

Скриншоты и управление окнами

Управление питанием: перезагрузка, выключение и т.д.

🧠 ИИ-помощник с доступом в интернет

Использует API Groq

Может отвечать на любые вопросы в реальном времени

Понимает контекст и ведёт диалог

💬 Телеграм-бот интерфейс

Управление Jarvis через чат

Возможность задавать команды или вопросы

Отправка отчётов и уведомлений прямо в Telegram

🗣 Голосовое управление (планируется)

Распознавание речи через SpeechRecognition

Озвучка ответов с помощью pyttsx3 или gTTS

💡 Пример сценария использования

Я нахожусь вне дома, но хочу проверить, запущен ли код на моём ПК.

Я пишу боту в Telegram:

Jarvis, покажи экран

Jarvis делает скриншот и отправляет его мне.

Я пишу:

Открой VSCode

Jarvis запускает Visual Studio Code.

Потом я могу спросить:

Что такое асинхронность в Python?

Jarvis ищет ответ через интернет и отвечает простыми словами.

🚀 Цель проекта

Создать собственного цифрового помощника, который:

сочетает в себе интеллект и утилитарность,

позволяет управлять ПК на расстоянии,

и имеет базовый интеллект с доступом к интернету.
